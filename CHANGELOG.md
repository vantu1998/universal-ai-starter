# Changelog

Development history of **universal-ai-starter** itself. This file is NOT shipped to users;
`STATE.md` is a clean template and must never contain this repo's own dev log.

## [Unreleased]
- Automatic GitHub Template Cleanup Action (`.github/workflows/template-cleanup.yml`):
  When users click "Use this template", the action automatically removes upstream maintainer
  files (`CHANGELOG.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CODEOWNERS`, `install.sh`, `install.ps1`),
  personalizes `AGENTS.md` and `STATE.md` with the new repository name, generates a clean project
  `README.md`, and self-destructs after committing.
- Separate template content from maintainer content: clean `STATE.md`, CI guard against dev traces,
  `ci.yml` gated to the upstream repo.

## [1.1.0] - 2026-10-23
- Sync scripts read command/skill descriptions from frontmatter; `sync.ps1` and `sync.sh` produce byte-identical output.
- Installers: `AI_OS_REF` pinning, `AI_OS_SRC` local source, never overwrite existing `.ai/` files.
- Added `CLAUDE.md`, `GEMINI.md`, `.github/copilot-instructions.md`, `.ai/rules/security.md`, `.claude/settings.json`.
- Added PreToolUse guard hook (`scripts/hooks/guard-bash.sh`) and scoped Cursor rules generated by sync.
- CI: permissions, concurrency, adapter drift check, shellcheck, frontmatter validation, hook test; actions pinned by SHA; Dependabot.
- Added SECURITY, CONTRIBUTING, CODEOWNERS, PR template; AGENTS.md gained Commands/Boundaries/Parallel agents.

## [1.0.0]
- Initial release: `.ai/` commands, skills, rules, knowledge; install scripts; native tool sync engine.
